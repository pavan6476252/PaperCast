# Changelog

All notable changes to PaperCast will be documented in this file.

<Version version="1.1.0" date="2026-08-05">

This release introduces major enhancements to the table component, including cell spanning, and adds this new changelog page.

### Added

- <Badge type="feature">Feature</Badge> Added support for `colspan` and
  `rowspan` in Table Headers.
- <Badge type="feature">Feature</Badge> Created a dedicated Changelog page for
  the marketing site.
- <Badge type="improvement">Improvement</Badge> Improved layout measurement
  accuracy for nested containers.

### Fixed

- <Badge type="fix">Fix</Badge> Resolved an issue where PDF exports would
  sometimes clip the last line of text on a page.

</Version>

<Version version="1.0.0" date="2026-07-20">

Initial public beta release of PaperCast!

### Added

- <Badge type="feature">Feature</Badge> Visual Playground for drag-and-drop
  document building.
- <Badge type="feature">Feature</Badge> Core Auto-Pagination Engine.
- <Badge type="feature">Feature</Badge> Next.js integration bindings.
- <Badge type="feature">Feature</Badge> Support for basic text, images, rows,
  columns, and tables.

</Version>
