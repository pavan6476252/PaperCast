# Changelog

All notable changes to PaperCast will be documented in this file.

<Version version="0.3.7" date="2026-08-16">

This release improves the visual polish of our engineering blogs with crisp, scalable vector banners!

### Improved

- <Badge type="improvement">Improvement</Badge> **Mermaid SVG Banners**: We've
  replaced static cover images on the engineering blogs with dynamically
  generated Mermaid SVG architecture diagrams for a cleaner,
  resolution-independent look.
- <Badge type="improvement">Improvement</Badge> **Scalable Image Layouts**:
  Updated the blog layout and listing grids to gracefully contain SVG banners
  without cropping them, ensuring they look perfect regardless of screen size.

</Version>

<Version version="0.3.6" date="2026-08-16">

This release opens up PaperCast to the world, allowing developers to embed the powerful visual playground directly into their own web applications!

### Added

- <Badge type="feature">Feature</Badge> **Third-Party Embedding**: You can now securely embed the PaperCast Playground via `<iframe>` and inject dynamic schemas on the fly using the `window.postMessage` API.
- <Badge type="feature">Feature</Badge> **Live Example & Docs**: Added
  comprehensive documentation and a live HTML example demonstrating how to
  integrate the playground into your own host application seamlessly.

</Version>

<Version version="0.3.5" date="2026-08-16">

This release introduces comprehensive updates to the documentation and brings highly requested tools to the AI agent ecosystem!

### Added

- <Badge type="feature">Feature</Badge> **Page Break Widget**: Added a dedicated
  `pageBreak` widget to manually force pagination boundaries where the
  auto-pagination engine needs a hint.
- <Badge type="feature">Feature</Badge> **Search Icons Tool**: Introduced a new
  `search_icons` MCP tool to help agents seamlessly navigate the massive 1,400+
  `lucide-react` icon library.
- <Badge type="feature">Feature</Badge> **Workspace MCP Tools**: Agents can now
  directly manage saved workspaces using the new `workspace_*` tools, allowing
  AI to scaffold entire environments for users.

### Improved

- <Badge type="improvement">Improvement</Badge> **Capabilities Documentation**:
  Comprehensively updated the `mcp-capabilities.mdx` documentation to reflect
  the full breadth of the current system, ensuring no gaps between the agent's
  toolset and public docs.
- <Badge type="improvement">Improvement</Badge> **Conditional Rendering Docs**:
  Better explanations of the powerful new `visibleIf` feature and how to use
  data-driven conditionals for widgets.

</Version>

<Version version="0.3.4" date="2026-08-15">

This release introduces native icons, fine-grained visibility controls, and a smarter property editor!

### Added

- <Badge type="feature">Feature</Badge> **Icon Node**: A new native `IconNode`
  powered by Lucide React, fully integrated into the document schema.
- <Badge type="feature">Feature</Badge> **Conditional Visibility**: Added a new
  `visibleIf` property that uses expressions to intelligently prune nodes before
  pagination based on your data.
- <Badge type="feature">Feature</Badge> **Native Color Picker**: Enhanced the
  Property Panel's color inputs to include a native color picker that
  auto-completes theme variables.

### Improved

- <Badge type="improvement">Improvement</Badge> **Icon Dropdown**: Added a
  searchable dropdown in the Properties panel for selecting `lucide-react` icons
  instantly.

</Version>

<Version version="0.3.3" date="2026-08-08">

This release fixes critical schema validation and Vercel bundling issues to ensure reliable PDF downloads in all environments!

### Fixed

- <Badge type="fix">Fix</Badge> **Vercel Chromium Bundling**: Corrected the
  `outputFileTracingIncludes` path in Next.js config so that
  `@sparticuz/chromium` binaries are properly hoisted and bundled on Vercel
  serverless functions, fixing the "Directory not found" 500 error.

</Version>

<Version version="0.3.2" date="2026-08-08">

### Fixed

- <Badge type="fix">Fix</Badge> **Vercel Build Crashes**: Fixed a persistent
  Vercel deployment crash by removing aggressive Next.js file tracing that was
  copying massive symlink directories from the pnpm store, and added a
  `.vercelignore` to prevent uploading heavy local cache directories.

</Version>

<Version version="0.3.1" date="2026-08-08">

This release restores Vercel deployments by optimizing the size of our serverless functions!

### Fixed

- <Badge type="fix">Fix</Badge> **Deployment Failures**: Resolved an issue where
  deploying the app to Vercel would fail with an "Unexpected error" during
  output deployment. The rich text editor dependencies are now lazily loaded,
  significantly reducing the serverless function size and staying within the
  50MB limit.

</Version>

<Version version="0.3.0" date="2026-08-08">

This release introduces fine-grained Content Locking, shifts Rich Text Preferences to the node level for better control, and significantly hardens our codebase's TypeScript strictness!

### Added

- <Badge type="feature">Feature</Badge> **Content Lock (`lockContent`)**: You
  can now lock specific nodes within the document to prevent accidental textual
  edits while still allowing styling and layout adjustments.

### Improved

- <Badge type="improvement">Improvement</Badge> **Node-Level Rich Text
  Preferences**: We migrated global `autoDeconstruct` configurations directly to
  the node-level `config`, giving you much finer control over how individual
  blocks of text behave.
- <Badge type="improvement">Improvement</Badge> **Zero-Tolerance Type Safety**:
  Entirely eliminated `any` types from our AST manipulation systems and added a
  strict `typecheck` pre-commit hook to guarantee rock-solid type safety going
  forward.

</Version>

<Version version="0.2.6" date="2026-08-08">

This release significantly improves the core `@papercast/react` architecture by fully decoupling heavy rich-text dependencies from the headless library!

### Improved

- <Badge type="improvement">Improvement</Badge> **Lightweight React Package**:
  Extracted all `TipTap` dependencies from the core `@papercast/react` package
  into the web application, dramatically reducing the bundle size for anyone
  building custom renderers.
- <Badge type="improvement">Improvement</Badge> **Dynamic Property Editors**:
  Introduced a new `renderPropertyEditor` seam in the Node Registry, allowing
  host applications to seamlessly inject custom property panels and editors.
- <Badge type="improvement">Improvement</Badge> **Reusable UI Primitives**:
  Exposed `PropertyGroup`, `StringProp`, `ColorProp`, and more from the core
  package, making it effortless to build visually consistent custom node
  configuration panels.

### Added

- <Badge type="feature">Feature</Badge> **Native Inline Formatting**: Upgraded
  the `text` node within the Web App Playground to support native inline rich
  text formatting (bold, italic, colors, highlight) while maintaining strict
  headless engine compatibility.

</Version>

<Version version="0.2.5" date="2026-08-07">

This release restores PDF export functionality in production and resolves automated release workflow issues!

### Fixed

- <Badge type="fix">Fix</Badge> **PDF Export in Production**: Resolved a
  critical issue where generating a PDF on Vercel would crash with a missing
  binary error. The build process now correctly traces and includes the
  Sparticuz Chromium binaries from the monorepo root.
- <Badge type="fix">Fix</Badge> **Automated Release Workflows**: Fixed an issue
  in the Changesets configuration where an incorrect package name was preventing
  the automated release workflow from successfully publishing packages to NPM.

</Version>

<Version version="0.2.3" date="2026-08-07">

This release introduces an incredibly fluid, multi-touch canvas experience for mobile and trackpad users, making document editing feel like a native application!

### Added

- <Badge type="feature">Feature</Badge> **Multi-Touch Gestures**: You can now
  seamlessly pinch-to-zoom on mobile and trackpads!
- <Badge type="feature">Feature</Badge> **Concurrent Pan & Zoom**: Panning and
  zooming simultaneously is now fully supported. As you pinch to zoom, the
  canvas naturally anchors and shifts based on the midpoint of your fingers,
  creating a flawless infinite-canvas feel.

### Improved

- <Badge type="improvement">Improvement</Badge> **Silky Smooth 60FPS**: The new
  gesture engine bypasses heavy React renders and updates the DOM directly
  during your pinch, guaranteeing a buttery smooth scaling experience with zero
  lag.

</Version>

<Version version="0.2.2" date="2026-08-07">

This release fixes a visual layout issue in the Playground to ensure the Workspace Explorer aligns perfectly with the editor's boundaries.

### Fixed

- <Badge type="fix">Fix</Badge> **Workspace Sidebar Gap**: Fixed an issue where
  the Workspace Explorer would not expand to fill the entire sidebar width on
  desktop and mobile screens, leaving an empty visual gap between the explorer
  and the document canvas.

### Improved

- <Badge type="improvement">Improvement</Badge> **Mobile UX Polish**: Refined
  the mobile Playground experience by adding smooth slide-in entry animations to
  the Properties panel and respecting safe-area insets to prevent UI overlap
  with the iOS Home Indicator.
- <Badge type="improvement">Improvement</Badge> **Mobile Back Button
  Navigation**: Opening a panel on mobile now automatically pushes state to your

  panel instead of throwing you out of the playground entirely. Full support for
  nested overlays included!

</Version>

<Version version="0.2.1" date="2026-08-07">

This release focuses on solidifying the editor experience, resolving critical mobile interaction bugs, and squashing PDF export errors for a much smoother workflow!

### Added

- <Badge type="feature">Feature</Badge> **Custom PDF Naming**: You can now give
  your downloaded PDFs custom filenames right from the export prompt.
- <Badge type="feature">Feature</Badge> **Visual Empty States**: Empty
  containers like Rows and Columns now display a clear visual indicator
  (diagonal stripes) in the editor, making them easy to spot without showing up
  in your final print.

### Improved

- <Badge type="improvement">Improvement</Badge> **Mobile Drag & Drop UX**:
  Drastically improved the mobile playground. Swiping the widget toolbar now
  scrolls flawlessly without accidentally dragging widgets. Added a dedicated
  drag handle for precise control.
- <Badge type="improvement">Improvement</Badge> **Ghost Dragging UI**: Dropping
  widgets now displays a clean, semi-transparent ghost image instead of a solid
  block.

### Fixed

- <Badge type="fix">Fix</Badge> **LAN Compatibility Crash**: Resolved a critical
  crash (`crypto.randomUUID is not a function`) that occurred when accessing the
  playground over a local IP network.
- <Badge type="fix">Fix</Badge> **PDF Export Empty Text**: Fixed an issue where
  the "Empty" visual placeholder text was incorrectly showing up in exported
  PDFs. Empty widgets now maintain their size for spacing but are completely
  invisible in print.
- <Badge type="fix">Fix</Badge> **PDF Export Warnings**: Fixed console warnings
  during PDF generation by properly managing Object URL cleanup lifetimes.
- <Badge type="fix">Fix</Badge> **Type Strictness & Validation**: Patched
  missing schema types and suppressed internal validation memory exhaustion
  errors during PDF generation.

</Version>

<Version version="0.2.0" date="2026-08-06">

This massive release supercharges the Table widget, introducing advanced row spanning, dynamic data grouping, and a complete UI overhaul for table configuration!

### Added

- <Badge type="feature">Feature</Badge> **Dynamic Cell Merging**: Introduced a
  powerful new `mergeBy` configuration for columns, allowing intelligent row
  spanning by grouping identical contiguous data.
- <Badge type="feature">Feature</Badge> **Static Rows**: You can now build
  advanced layouts inside tables using fixed Header, Body, and Footer rows
  independent of mapped data.
- <Badge type="feature">Feature</Badge> **Advanced Table Snippets**: Added 5 new
  complex schema templates to the Template Gallery demonstrating multi-level
  spanning, nested grouping, and invoice totals.

### Improved

- <Badge type="improvement">Improvement</Badge> **Property Panel UI**: Extracted
  table row editors into a clean, reusable `<StaticRowsEditor />` and added a
  seamless `<MultiSelectProp />` for array configuration, making the builder
  faster and easier to use.
- <Badge type="improvement">Improvement</Badge> **Pagination Safety**: Upgraded
  the core pagination engine to ensure dynamic data groups are never severed by
  a page break.

</Version>
