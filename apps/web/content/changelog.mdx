# Changelog

All notable changes to PaperCast will be documented in this file.

<Version version="0.1.2" date="2026-08-05">

This release introduces significant enhancements to our documentation layout, a refined Playground experience, and new workflow superpowers!

### Added

- <Badge type="feature">Feature</Badge> **Mobile Sidebar Drawer**: Implemented a
  responsive slide-out drawer for seamless navigation on smaller devices.
- <Badge type="feature">Feature</Badge> **Workflow Skills**: Added new
  intelligent code-review workflow tools to streamline the development
  lifecycle.

### Improved

- <Badge type="improvement">Improvement</Badge> **Playground UI**: Extracted
  page sizing logic and refactored the Playground toolbar for cleaner, more
  intuitive document editing.
- <Badge type="improvement">Improvement</Badge> **Docs Layout**: Upgraded the
  documentation sidebar and content structure for better readability and easier
  exploration of snippets and widgets.

</Version>

<Version version="0.1.1" date="2026-08-05">

This release brings a highly polished, premium UI overhaul to our marketing pages, introducing true Glassmorphism to our dialogs and smart semantic theming.

### Improved

- <Badge type="improvement">Improvement</Badge> **Changelog Dialog**: Upgraded
  the "What's New" modal with a stunning frosted-glass aesthetic
  (Glassmorphism), translucent buttons, and dynamic lighting.
- <Badge type="improvement">Improvement</Badge> **Early Access Badge**: Refined
  the hero chip to adapt seamlessly to light and dark themes using our semantic
  design system.

</Version>

<Version version="0.1.0" date="2026-08-05">

This release introduces a brand new Changelog page to keep you updated on all the latest features, along with a significantly improved mobile navigation experience!

### Added

- <Badge type="feature">Feature</Badge> **Changelog Page**: A beautifully
  designed, dedicated page to view all release notes, complete with semantic
  categorizations.
- <Badge type="feature">Feature</Badge> **Mobile Navbar**: A completely
  redesigned, animated, full-screen mobile menu overlay for a premium navigation
  experience on smaller devices.
- <Badge type="feature">Feature</Badge> **App Versioning**: You can now see the
  current version of PaperCast seamlessly integrated into the footer and the
  mobile menu.

### Improved

- <Badge type="improvement">Improvement</Badge> Refactored the Marketing Layout
  to cleanly separate Server Components from the Header Client Component,
  significantly improving React performance.
