# ListTile Widget

The `ListTileNode` is a compound widget for standard UI lists consisting of a Title, Subtitle, and optional leading/trailing elements.

```json
{
  "id": "tile-1",
  "type": "listTile",
  "layout": {},
  "props": {
    "titleLiteral": "Software Engineer",
    "subtitleLiteral": "Acme Corp - 2021-Present"
  }
}
```

## Properties

- `titleLiteral` / `titleBind`: The primary text.
- `subtitleLiteral` / `subtitleBind`: The secondary, smaller text.
