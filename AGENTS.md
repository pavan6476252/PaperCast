## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Custom labels prioritizing human solving: `needs-triage`, `needs-info`, `agent-assist`, `ready-for-dev`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout with a root `CONTEXT-MAP.md` pointing to per-package `CONTEXT.md` files. See `docs/agents/domain.md`.
