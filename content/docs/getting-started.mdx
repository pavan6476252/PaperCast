# Getting Started with FormCast

Welcome to the FormCast API documentation. 
FormCast is a Schema-First Document Builder. You design your layout using a JSON schema, and our engine renders it dynamically.

## API Overview
To programmatically generate PDFs, send a POST request with your JSON schema to `/api/pdf`.

```js
fetch('/api/pdf', {
  method: 'POST',
  body: JSON.stringify(mySchema)
});
```
