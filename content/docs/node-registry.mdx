# Node Registry

FormCast fundamentally separates the structure of a document (JSON Schema) from its visual representation (React Components). This is achieved through the `NodeRegistry`.

The `NodeRegistry` maps a `type` string from the JSON AST to a `NodeTypeDefinition`.

## API Reference: `NodeTypeDefinition`

When you create a new widget or node type in FormCast, you must register it with the `NodeRegistry` using this interface:

```typescript
export interface NodeTypeDefinition<TNode extends BaseNode = BaseNode> {
  // The string type in the JSON schema (e.g. 'text', 'row', 'image')
  type: string;

  // A function that calculates the height of the node based on available width
  measure: (node: TNode, ctx: MeasureContext) => number;

  // The React component responsible for rendering this node
  render: React.ComponentType<{
    node: TNode;
    path?: string;
    isSelected?: boolean;
    onSelect?: (e: React.MouseEvent) => void;
    pageContext?: { pageNumber: number; pageCount: number };
  }>;

  // Optional logic for splitting the node across pages
  split?: (
    node: TNode,
    remainingHeight: number,
    ctx: SplitContext
  ) => [TNode, TNode | null, number?] | null;
}
```

<Callout type="info" title="Why is measuring separate from rendering?">
  Because FormCast runs `OffscreenMeasurer.tsx` silently before doing any
  pagination, the engine needs a lightweight way to ask a node how tall it will
  be given a specific width constraint, without actually rendering the heavy
  React tree to the screen.
</Callout>

## Registering a Node

Here is an example of registering a simple "divider" node:

```typescript
NodeRegistry.register({
  type: "divider",
  measure: () => 10, // A divider is always 10px tall
  render: ({ node }) => (
    <div style={{ height: "1px", background: "black", margin: "4px 0" }} />
  ),
});
```

## Tutorial: Creating a Custom Signature Widget

Let's say you want to add a "Signature Box" to your document builder.

**1. Create the React Component**
First, build the component that will render the signature line.

```tsx
// src/components/renderer/nodes/SignatureNode.tsx
import React from "react";
import { BaseNode } from "../../../types/schema";

export const SignatureNode = ({ node }: { node: BaseNode }) => {
  return (
    <div className="mt-8 flex flex-col w-64">
      <div className="border-b border-black h-12" />
      <span className="text-sm text-slate-500 mt-2 font-italic">Sign Here</span>
    </div>
  );
};
```

**2. Register it with the Engine**
In your widget registration file (e.g., `src/registry/categories/basic.ts`):

```tsx
import { NodeRegistry } from "../NodeRegistry";
import { SignatureNode } from "../../components/renderer/nodes/SignatureNode";

NodeRegistry.register({
  type: "signature",
  // A signature box is roughly 70px tall (48px line + 20px text)
  measure: () => 70,
  render: SignatureNode,
});
```

**3. Add it to the DnD Widget Menu**
Now, define the default JSON payload that should be injected into the AST when a user drags the widget from the sidebar into the document:

```typescript
// Inside your widget category definitions
export const signatureWidgetDef = {
  id: "signature-widget",
  name: "Signature Box",
  icon: "PenTool", // Lucide icon
  defaultNode: {
    type: "signature",
    layout: {
      marginTop: 20,
    },
  },
};
```

That's it! The parser will now automatically measure, paginate, and render your custom Signature node.
